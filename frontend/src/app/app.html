WINDOWS TERMINAL · POWERSHELL

Angular, .NET and Python. One launcher.

Install Node.js 24, the .NET 10 SDK and Python 3.11 or newer. Setup creates an isolated .venv, installs Angular/Python dependencies, generates matching tokens and restores the .NET projects.

01

Install and configure

Set your own model key in agent-service/.env. Keep the generated internal token unchanged. Existing files are preserved; blank CLAUDE_MODEL uses the SDK default and turns accept 1–10.

02

Understand the gateway

backend/.env contains only the private Python URL and matching service token. It never needs the Anthropic key. Keep TRUST_PROXY=0 locally; only enable it behind a controlled HTTPS ingress.

03

Start development

Wait for Angular, then open http://127.0.0.1:6600. ASP.NET Core listens on 9800 and private Python on 9801. The launcher waits for both services; Ctrl+C stops its own children.

Separate terminals can run npm run dev:agent, npm run dev:backend and npm run dev:frontend. Read the gateway API reference.

04

Build and run production locally

Stop development first. ASP.NET Core serves compiled Angular and its API at http://127.0.0.1:9800; the private Python process runs alongside it. DEPLOYMENT.md describes the two-container option, private networking, HTTPS and user access controls.

Key presence is not provider authentication.

Health reports the private service’s key-presence flag. It does not verify model access or credits. The internal service token is separate from end-user authentication.
